CD22/Siglec-2 是 B 细胞相关的唾液酸识别共受体，兼具膜上空间调节、胞内抑制信号与内吞回收功能。它帮助 B 细胞在基础生存信号、有效抗体应答和自身耐受之间保持平衡；药物递送只是这些生物学性质的一种应用。

01

CD22 的长胞外结构连接糖链识别与 B 细胞共受体功能

CD22 又称 Siglec-2，是以 B 细胞为主要研究背景的单次跨膜糖蛋白。早期人源克隆研究在正常活化 B 细胞及多种 B 细胞系中检出表达，而所测活化 T 细胞和若干非淋巴组织未检出；这提供细胞偏向证据，并不构成所有组织绝对阴性的清单。主要全长形式的胞外区包含七个免疫球蛋白样结构域，远端区域识别唾液酸化糖链，胞内尾部提供可磷酸化的调节位点。人结构研究发现，胞外区呈较延长、倾斜且有限柔性的排列，为接触本细胞和邻细胞的糖链提供几何基础。CD22 因而同时是表面识别分子与信号定位平台，而不是分泌抗体或自带激酶的生长因子受体。[3][4]

02

顺式糖链遮蔽与反式细胞接触可以同时存在

CD22 偏好识别末端含 α2,6 连接唾液酸的糖链；人结构研究将这一选择性联系到预先形成的结合口袋和特定发夹结构。初始 B 细胞表面本身具有大量相关糖链，能以顺式方式占据或限制 CD22 的配体位点，使外源探针难以接近，这种现象常称遮蔽。但遮蔽不等于永久封闭：原始细胞接触研究显示，即使存在顺式配体，CD22 仍可重分布到与其他 B 或 T 淋巴细胞接触的部位，参与反式识别。局部密度、多价排列和膜上位置因此与单个糖链亲和力同样重要。可溶探针的结合强弱，不能直接代表活细胞突触中的占据和功能。[4][5]

03

纳米簇和糖基化控制 CD22 接近 BCR 的机会

在初始 B 细胞上，CD22 并非均匀铺开或始终紧贴 BCR。超分辨与单分子研究发现，它以快速移动的纳米簇存在，糖链识别区、CD45 和皮质细胞骨架共同改变簇组织及移动性。这让数量相对有限的 CD22 也能反复接近多个信号区域。糖链作用因此不能简化为结合就抑制、不结合就激活：小鼠缺失 ST6Gal-I 后，顺式配体减少，却出现 CD22 与 BCR 接近增加、基础 IgM 内吞加快和应答减弱；同时删除 CD22 可逆转其中多项变化。这类结果说明配体也会限制抑制受体的可达范围，最终方向取决于空间重新分配，而非只有占位率。[6][7]

04

Lyn–SHP-1 与接头蛋白共同约束 BCR 的钙响应

BCR 被启动后，CD22 胞内酪氨酸可被磷酸化，其 ITIM 为 SHP-1 提供停泊位点，帮助降低近端信号。原始小鼠研究表明，在所测 BCR 应答中，Lyn 缺失会妨碍 CD22 磷酸化、SHP-1 招募及钙响应抑制，支持这条经典负反馈链。胞内尾部也含非 ITIM 接头位点；细胞模型进一步显示，GRB2 可联系 CD22 与质膜钙泵 PMCA，促进钙从胞质排向胞外。限制钙释放和促进钙外排是相互补充的调节方式，不能把所有胞内位点都标成同一抑制基序。上述机制说明 CD22 调整信号强度与持续时间，并非让 BCR 永久失去反应能力。[8][9][10]

05

抑制受体也能支持正常 B 细胞寿命和有效应答

把 CD22 简单看作阻止抗体产生的刹车，会忽略它对正常反应质量的支持。缺失小鼠研究显示，CD22 参与成熟 B 细胞寿命调节及对胸腺非依赖抗原的正常抗体应答；受体减少并不保证所有免疫功能都会增强。另一些随年龄观察的缺失小鼠出现高亲和、自身反应性 IgG，提示 B 细胞阈值的较小偏移也能累积成耐受缺陷。但原研究中的自身抗体并未自动伴随典型肾脏损伤，说明血清标志与器官疾病仍是不同结局。CD22 的生理任务因此包括维持可用细胞库、限定过强反应和降低误识别自身的机会，这些作用受遗传背景及年龄影响。[11][12]

06

生发中心通过物种不同的糖链改造重新调节 CD22

B 细胞进入生发中心后，不仅改变转录程序，也重塑 CD22 所处的糖链环境。人鼠原始研究都观察到高亲和顺式配体减少，使 CD22 更容易识别反式配体，但实现方式不同：小鼠由 Neu5Gc 向 Neu5Ac 转换，人则减少相关糖链上的硫酸化修饰。后续小鼠遗传研究发现，若强制保留原有配体，生发中心细胞的生存、记忆及浆细胞输出和抗体亲和成熟会受损，且效应依赖 CD22。这支持糖链重塑参与正常应答选择，而不仅是染色标记变化。小鼠的代谢酶机制不能直接搬到人类；糖链改造、CD22 去除和一般 BCR 抑制也不是彼此等价的操作。[13][14]

07

邻细胞的自身糖链为抗原识别叠加抑制信息

BCR 识别细胞表面的抗原时，还会遇到同一接触面上的糖链。原始细胞研究显示，若呈递抗原的细胞同时具有 CD22 可识别的 α2,6 唾液酸化结构，B 细胞活化会受到 CD22 依赖的抑制。这为自身组织把抗原信息与抑制线索同时传给 B 细胞提供了机制依据，但不是所有自身耐受的唯一解释。进一步的原始研究把抗原和 CD22 配体共同呈现在同一颗粒上，在人鼠 B 细胞中诱导特异性抑制或凋亡，并在小鼠形成抗原特异耐受。这里的共呈递几何关系尤为关键：单独结合 CD22 的糖链、单独抗原与二者共定位，并不能预设为相同效应。[15][16]

08

持续内吞与回收使受体周转和所携物质去向分离

CD22 胞内尾部可与网格蛋白包被小窝的接头组分 AP50 相互作用，为受体介导内吞提供分子连接。但进入细胞并不意味着受体必然立即降解。原始 B 细胞研究发现，CD22 可在细胞表面与内体之间持续回收；糖链型所携物质可在酸性内体释放并累积，而所测抗体若仍与受体结合，则可能随 CD22 返回表面。不同识别方式因此改变受体和结合物的共同旅程。其正常意义首先是表面识别与胞内周转相联系，而研发应用还需考虑结合物解离、分选和载荷释放。一次荧光摄入或表面信号下降，不能单独证明发生了有效的胞内递送或持续受体清除。[17][18]

09

调节生理信号、递送载荷和重定向杀伤是不同干预

CD22 在多种 B 细胞肿瘤中保留表达，为识别病变细胞提供入口，但这不说明它就是每种肿瘤的生长驱动因子。改变 CD22 与 BCR 的接近可调节正常抑制信号；抗体偶联药物则利用识别及内吞，把后续效应交给所携载荷，官方机制资料将 DNA 损伤与抗体识别明确分开。CD22 靶向细胞治疗的原始人研究还显示，肿瘤表面抗原密度下降可以影响识别和疾病逃逸，即便并非所有细胞完全阴性。因此，表面量、糖基化、内吞和靶细胞自身敏感性共同限制不同模态的结果。某种干预能清除细胞，并不等于其疗效来自恢复 CD22 的天然抑制功能。[19][20][4]

继续阅读实验评价

糖链结合、CD22 与 BCR 的接近、SHP-1 招募、钙信号以及内吞后去向分别提供不同层级的信息。CD22 阳性不能单独预测抑制强度或载荷效力；比较人鼠、初始与生发中心 B 细胞时，还应纳入糖链环境和表面可及性。
