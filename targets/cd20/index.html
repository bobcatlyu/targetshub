CD20 是 MS4A1 编码的四跨膜 B 细胞表面蛋白，参与膜上受体组织与 B 细胞状态调节。其正常生物学功能与抗体借助它募集补体、吞噬细胞或 T 细胞的治疗机制，需要分别理解。

01

MS4A1 编码的四跨膜蛋白以紧凑二聚体呈现表位

CD20 由 MS4A1 编码，属于 MS4A 膜蛋白家族，具有四段跨膜螺旋、大小两个胞外环，N 端与 C 端位于胞质侧。它没有受体酪氨酸激酶那样的大型胞内催化区。冷冻电镜捕获到紧凑的双桶状同源二聚体，胞外环及二聚体表面共同构成抗体识别环境。利妥昔单抗结合结构中，两个 Fab 除了接触 CD20，还彼此形成同型相互作用。因此，抗体面对的并非一条孤立的线性肽：膜内折叠、二聚界面和相邻抗体的位置都会影响结合后的组装。结构解释的是特定复合物，膜上更高阶组织还会随状态改变。[4][5][6]

02

表达随 B 细胞成熟与抗体分泌分化而变化

CD20 出现在前 B 细胞到成熟 B 细胞的发育区间，正常外周初始与记忆 B 细胞均可表达，因此它是 B 细胞谱系相关抗原，而非肿瘤专属标志。进入抗体分泌分化后，表达发生明显改变：人外周血表型研究发现，浆母细胞下调 CD20；多数终末分化浆细胞也失去或很少表达该蛋白。这使清除 CD20 阳性细胞与清除全部抗体来源并不等价。干预可减少许多成熟 B 细胞及其抗原呈递和后续分化贡献，而已经存在的低／阴性长寿命浆细胞未必被同一识别机制直接覆盖，原有抗体也不会随表面 B 细胞立即消失。[7][8][10]

03

人类缺陷揭示抗体应答功能，钙变化提供机制线索

人类 MS4A1 剪接缺陷病例为正常功能提供了直接线索：患者可保有正常数量的 B 细胞，却出现 IgG 降低、记忆细胞异常及对肺炎球菌多糖疫苗应答不足；配套小鼠实验也支持 CD20 参与有效的非 T 细胞依赖抗体应答。它因此更像调节细胞应答质量的膜组分，而不是 B 细胞形成所必需的单一开关。早期细胞研究中，改变 CD20 表达、膜筏定位或相关胞内片段会改变储存操作性钙进入。这支持其参与钙稳态与膜信号网络，但尚不能仅凭这些响应确定它自身构成生理离子孔道，也没有由此识别出统一天然配体。[9][10]

04

膜纳米组织把 CD20 连接到 BCR 与静息状态

CD20 的作用还体现在膜蛋白之间的空间关系。人 B 细胞研究发现，CD20 有助于维持静息状态下受体的纳米尺度组织；删除它后，IgM 类 BCR 与共受体 CD19 重新接近并发生相互作用，伴随短暂活化和多种表面蛋白内吞。重新表达 CD20 可使 Ramos 细胞恢复相应表面特征与静息状态。持续缺失还与 PAX5 向 BLIMP-1 的转录转变及浆细胞样分化相联系。利妥昔单抗结合也能引起部分相似膜重排，说明抗体既可募集外部效应，也会扰动靶细胞自身的组织状态；两类效应不应合并成唯一杀伤链。[11]

05

Type I 与 Type II 反映表位和组装方式差异

抗 CD20 抗体的 type I／II 分类描述结合后的组织及效应特征，不等同于开发代次。全长 CD20 结构比较显示，利妥昔单抗、奥法木单抗等 type I 复合物可作为进一步聚集的种子，提高局部抗体密度；奥妥珠单抗这一 type II 实例则形成较封闭的终止性复合物，限制继续募集。补体启动还需要结合在表面的 IgG 以合适的 Fc 间相互作用排列，利于 C1 识别与激活。因此，两个分子即使都能结合 CD20，也可能在补体募集方面表现不同；结合表位、抗体角度与 Fc 阵列共同连接了识别和细胞清除。[6][12]

06

Fc 募集与直接细胞效应提供多条清除路径

包被在 B 细胞上的抗体可通过 Fc 募集免疫效应：NK 细胞的 Fcγ 受体参与细胞毒作用，单核／巨噬细胞则可吞噬被包被的靶细胞。Fc 糖工程改变效应受体结合，是调节这一路径的方式；GA101 等糖工程抗体可增强 CD16a 相关效应，差异也受内源 IgG 竞争影响。另一些 type II 抗体实验中，同型细胞黏附、肌动蛋白重排和溶酶体参与的死亡即使没有补体也能发生，不能一概称为经典凋亡。靶细胞的膜状态和效应细胞的组成共同决定各路径权重，抗体类型并不意味着在每个组织都由同一机制主导。[8][13][14][23]

07

靶细胞内吞与邻近细胞移除都能减少表面抗原

CD20 结合抗体后并非固定留在表面。原代 B 细胞和肿瘤研究显示，利妥昔单抗复合物可被靶细胞内吞，且不同病种及患者间速度不同；靶细胞自身的 FcγRIIb 可在同一膜面与抗体 Fc 协同，促进这一过程并减少巨噬细胞对靶细胞的吞噬。另一种去向是单核／巨噬细胞接触包被细胞后，移走抗体及相关 CD20 膜复合物，称为 shaving／trogocytosis。这里抗原减少不必伴随整个靶细胞死亡。两种过程分别发生在靶细胞内与细胞间接触处，都会改变后续可用的抗原和抗体包被，却有不同的运输与效应关系。[15][16][17]

08

肿瘤异质性与治疗选择可产生持续的抗原逃逸

B 细胞肿瘤的 CD20 密度和可识别表位并不均一，治疗后还可能沿不同路径改变。纵向活检研究在部分 CD20 靶向双抗治疗后进展病灶中观察到 CD20 丢失，并发现 MS4A1 变异与表达或识别异常相联系。另一项原始研究显示，非翻译区剪接改变能降低 CD20 蛋白翻译，使 RNA 仍存在而表面蛋白明显减少。因此，膜上暂时内吞、稳定表达调节和抗原阴性克隆被选择，是时间尺度不同的逃逸方式。一个病灶保留 CD20 也不保证其他病灶相同；抗原端逃逸之外，免疫效应环境仍可影响清除结果。[18][19][22]

09

CD3 重定向把 CD20 识别接入 T 细胞杀伤

CD20×CD3 双特异性分子同时接触 B 细胞表面抗原和 T 细胞 CD3，使两类细胞形成有效接触并启动 T 细胞的细胞毒程序。原始临床前研究在患者来源白血病／淋巴瘤细胞及动物模型中证明了这一杀伤路径。与依赖补体或 Fcγ 受体募集的传统裸抗不同，这里的核心是靶细胞与 T 细胞的桥接；Fc 效应被显著削弱的分子仍可执行该功能，Fc 沉默还能减少不希望的旁路募集。其效果因此同时取决于可用 CD20、桥接几何和 T 细胞状态。共享 CD20 识别并不意味着双抗必须复制 type I 裸抗的补体组装方式。[20][21]
